Flex Sizing

  1. Flex-basis -: This use in case when there is extra space remaining so with the help of this we can give initial space to any of items inside it. agar maan lo flex direction column toh height ke across flex-basis set hogi and row mai hai toh width ke across set hogi.
    basically humne kisi ki flex basis 400px de diyaa toh agar extra space baach toh woh item khud ko 400px tak badha ke le jayegaaa
  2. Flex-grow-:It tells if there will be remaining extra empty space then how does the size of flex item increases
    By default flex-grow:1; 1x se grow karta hai and we can change it to 2x,3x,....

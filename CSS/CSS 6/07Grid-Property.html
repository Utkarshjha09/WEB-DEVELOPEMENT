Grid Playground - Grid properties

  1. justify-items:
    2. used for horizontal spacing on whole container
  2. align-items:
    3. used for vertical spacing on whole container
  3. justify-self:
    4. used for horizontal spacing on individual item
  4. align-self:
    5. used for vertical spacing on individual item
  5. place-items:
    6. used for whole container when vertically and horizontal both are same
  6. place-self:
    7. used for individual item when vertically and horizontal both are same

we have 3 values to set for this-: start, end, center
